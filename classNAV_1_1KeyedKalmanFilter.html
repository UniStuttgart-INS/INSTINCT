Performs the Normalized Innovation Squared (NIS) test on the measurement innovation 𝜹𝐳

Parameters
[in]nameIdCaller node for debug output

H_0: The measurement residual 𝜹𝐳 is consistent with the innovation covariance matrix 𝗦 The acceptance interval is chosen such that the probability that H_0 is accepted is (1 - alpha)

Returns
The hypothesis test result if it failed, otherwise nothing.
Attention
Needs to be called before the update
